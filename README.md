# Swear Jar

Collect slang, swear words and insults from every language. Swap them face to face with a friend, quiz yourself, and score points.

Live: https://asiansidekick.github.io/swearjar/

- `index.html` is the whole app (built from `src/`, run `python3 build.py` in `src`).
- Swapping needs no server: taught words travel inside the QR code link.
- "Share my words to improve Speakeasy" is off by default and sends only the word, language, meaning and rudeness.
